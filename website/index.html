Core System Architecture

Cryptex splits source payloads into uniform binary blocks (e.g. 512KB). Each block is encrypted independently using AES-256-GCM with cryptographically random 96-bit nonces, generating a signed cryptographic manifest JSON. Encrypted blocks are stored across cloud object storage buckets (AWS S3) and distributed globally via CloudFront Edge Point-of-Presence (PoP) locations over HTTPS TLS 1.3.

🔒

AES-256-GCM Cipher

Galois/Counter Mode authenticated encryption guarantees both confidentiality and tamper-resistance for every stored block.

📦

Block Chunking

Divides files into dynamic segments (64KB - 2048KB) for high-concurrency parallel S3 transfers and resilient streaming.

🌍

CloudFront Edge CDN

Origin Access Control (OAC) keeps S3 buckets private while delivering cached blocks at sub-20ms edge latency worldwide.

✅

SHA-256 Checksums

Automated pre-encryption vs post-reassembly SHA-256 hash comparison guarantees 100% data parity and corruption detection.

Quickstart & Deployment Guide

1. Local Environment Execution

# Install required dependencies
pip install cryptography streamlit pandas

# Run full automated unit test suite (100% pass target)
python run_tests.py

# Launch the interactive Streamlit Cloud Vault Dashboard
python -m streamlit run frontend/app.py

2. Cloud Static Site Deployment (S3 + CloudFront)

# Create S3 bucket for website hosting
aws s3 mb s3://cryptex-documentation-vault --region us-east-1

# Sync portfolio site assets to S3
aws s3 sync website/ s3://cryptex-documentation-vault/ --acl public-read

# Create CloudFront CDN distribution with Origin Access Control (OAC)
aws cloudfront create-distribution --origin-domain-name cryptex-documentation-vault.s3.amazonaws.com
